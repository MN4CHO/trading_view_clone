# Trading View Clone

## Instalación

Crear el entorno virtual

```bash
python3 -m venv venv
```

Activarlo

Linux / macOS

```bash
source venv/bin/activate
```

Windows

```powershell
venv\Scripts\activate
```

Instalar dependencias

```bash
pip install -r requirements.txt
```

## Ejecutar el preprocesamiento

```bash
python preprocess.py
```

## Ejecutar el proyecto

```bash
perl market.pl
```
